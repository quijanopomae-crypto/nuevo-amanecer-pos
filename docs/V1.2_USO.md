# V1.2 — Abrir y preparar la caja

Release `v1.2-production`. El propietario confirmó la caja real en la dirección local
indicada abajo, los datos comerciales presentes, la configuración de sincronización,
el respaldo `nuevo_amanecer_backup_completo_2026-09-11.json` y el visor desde Android.
Esta guía sirve para el uso diario y para recuperar la instalación sin perder datos.

## Abrir la aplicación completa

1. Extraer el paquete completo en una carpeta estable de esta PC.
2. Ejecutar `INICIAR_POS.cmd`. Necesita Node.js, ya disponible en la PC de preparación.
3. Usar siempre `http://127.0.0.1:8788/POS/index.html` en el mismo perfil de Chrome
   o Edge. Mantener abierta la ventana del iniciador durante el uso.
4. Abrir una sola pestaña de escritura. Teléfonos y otras PC usan el visor de lectura.

El servidor solo escucha en esta PC y sirve los archivos POS y la página auxiliar de
configuración incluidos en la lista del paquete. No publica credenciales ni el repositorio. La dirección estable permite
usar OCR con sus recursos incluidos. Abrir `POS/index.html` por doble clic utiliza
`file://`, donde OCR está expresamente deshabilitado.

## Si el negocio ya tiene datos

Antes de cambiar de archivo, dirección, puerto o perfil de navegador, abrir la caja
actual y descargar **Configuración → Importar datos → Respaldo completo → Descargar
respaldo JSON**. Guardar otra copia en una ubicación distinta. No borrar la caja anterior.

La nueva dirección tiene su propio almacenamiento. No verá automáticamente los datos
guardados bajo `file://` u otra dirección. Restaurar el respaldo completo desde la misma
pantalla de configuración, revisar la vista previa y comprobar los totales de ventas,
caja, créditos e inventario. Mantener una sola caja escritora después de la transición.
El ZIP del programa no contiene los datos del negocio.

## Conectar la caja a la nube

1. En el mismo perfil de Chrome/Edge de la caja, abrir
   `http://127.0.0.1:8788/tools/pos-local/setup.html`.
2. Introducir el SYNC_TOKEN vigente en el campo de contraseña y pulsar **Comprobar y guardar**.
3. Esperar **Conexión verificada y guardada**. Una clave inválida no reemplaza la anterior.
4. Cerrar la pestaña escritora anterior, si existe, y pulsar **Abrir POS**.

Esta página auxiliar comprueba la autenticación mediante una consulta sin crear ventas
y utiliza la API de configuración que V1.2 ya tenía. No cambia OUTBOX, finanzas ni la
interfaz del POS. El campo se vacía al terminar; no se imprimen credenciales.

El token queda guardado por el mecanismo existente en ese perfil del navegador; no se
incluye en el respaldo. `.dev.vars` configura las herramientas, no configura por sí solo
la caja comercial. La credencial debe verificarse contra el Worker activo. No cambiar
los tokens como parte de la instalación. Ante un fallo 401 previo, usar el reintento
explícito existente después de corregir la configuración; no alterar el OUTBOX a mano.

El teléfono abre `https://nuevo-amanecer-sync-lab.nuevo-amanecer-pos.workers.dev/read-only.html`
y utiliza exclusivamente READ_TOKEN. Solo muestra operaciones sincronizadas: el histórico
anterior no se carga automáticamente y no existe escritura desde ese visor.

## Cada jornada

Mantener un respaldo completo fuera de la carpeta del programa. La venta local puede
continuar sin internet; las operaciones pendientes se conservan para el reintento.
No borrar almacenamiento ni abrir otra caja escritora para resolver una caída de red.
Consultar `V1.2_RECOVERY.md` si es necesario recuperar la aplicación o los datos.
