## Interfaces and isolation

- Accumulative migration: `0006_canonical_promotion.sql`; 0001..0005 unchanged.
- Mapping/schema: `a6-mapping-v1` / `a6-schema-v1`; exact dictionary and policy
  exported from `tools/cloudflare-lab/src/a6-mapping.js`.
- POST `/commands/canonical.freeze`, `/commands/import.promote`,
  `/commands/canonical.rollback`: active A2 writer authentication.
- Promotion accepts identity/control only. `phase=prepare` builds immutable,
  invisible candidate batches; `phase=publish` reconciles and publishes atomically.
  Phase does not change logical identity. Same request returns its durable receipt.
- GET `/read/canonical/{status,products,customers,credits,credit-payments,sales,
  sale-items,inventory-movements,cash-movements}` uses READ_TOKEN, no-store and
  generation/epoch/revision-bound cursors. Legacy reads remain separate and fenced.
- GET `/imports/canonical/{promotion_id}?entity_type=...` is writer-authorized,
  paginated audit provenance, including invisible/abandoned candidates.
- All A6 routes require localhost/127.0.0.1 and `A6_LOCAL_GATE=enabled`. They are
  unavailable by default. `A6_LOCAL_DATABASE_ID` must match the operational manifest.

`A6_API_CONTRACT` in `a6-canonical.js` describes the exact environment and request
fields. `A6_OPERATIONAL_MANIFEST` includes environment/database, Worker/client
hashes, operator, backup hash, exact run identities/revision, mapping/schema/policy,
expected counts/amounts/dates and zero local pending/delta counts. Its canonical
JSON/hash is durable and part of the request identity. These are operator
attestations; the server does not independently measure its own build or external
devices. The local harness measures its actual bundle, client, database and backup.

Freeze checks zero A3/journal traffic and SQL triggers fence legacy writers even
if they raced the HTTP check. Rollback uses CAS, writer fencing and first-live NULL;
it only restores a pointer/read-only mode, never legacy write permission. It can
abandon a PREPARED candidate under its own freeze. Imported stock opening/current
values and historical payments never replay inventory, cash or sale effects.
