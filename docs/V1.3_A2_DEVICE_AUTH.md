## Objetivo
Implementar autenticación server-side mínima, identidad de dispositivo y revocación para V1.3 Mobile Cloud.

## Arquitectura
PWA/Android -> Cloudflare Worker -> D1.

Inicialmente:
- un solo dispositivo writer activo;
- otros dispositivos read-only;
- sin multiwriter.

## Alcance A2
1. Inspeccionar Worker y schema/migraciones D1 actuales.
2. Crear migración D1 versionada y no destructiva para dispositivos.
3. Registro mínimo:
   - device_id estable
   - role: writer | read_only
   - status: active | revoked
   - credential_hash o equivalente seguro
   - created_at
   - last_seen_at
4. Nunca almacenar credenciales en texto plano.
5. Máximo un writer activo.
6. Escrituras protegidas requieren autenticación server-side válida.
7. Writer activo con credencial válida: autorizado.
8. Read-only en escritura: rechazado.
9. Revoked: rechazado.
10. Credencial inválida: rechazada.
11. Health permanece público.
12. Mantener compatibilidad con A1 PWA.
