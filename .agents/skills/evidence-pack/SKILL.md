# Evidence Pack

Incluye identidad Git/worktree, manifest digest, contratos, gates, historial, comandos, pruebas, resultados, F1-F11, hechos, hipótesis, incógnitas, veredicto, riesgos residuales y `NEXT_ACTION`. Verifica SHA-256.
