# Evidencia del laboratorio

Aquí pueden registrarse resultados reproducibles de experimentos LAB.

La evidencia debe indicar:
- ID del experimento;
- commit probado;
- pasos de prueba;
- resultado PASS/FAIL;
- riesgos pendientes;
- decisión: DESCARTAR, ITERAR o CANDIDATO_A_CANON.

No incluir datos comerciales reales ni secretos.
