# Fixtures del laboratorio

Solo datos sintéticos o anonimizados creados específicamente para pruebas.

Prohibido colocar aquí:
- respaldos reales del negocio;
- ventas, clientes, créditos o inventario real;
- credenciales, tokens o claves;
- exportaciones de producción.

Los datos comerciales reales permanecen fuera del repositorio.
