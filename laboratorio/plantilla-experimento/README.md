# Plantilla de experimento

1. Crea una rama `lab/<nombre>`.
2. Copia esta plantilla dentro de `laboratorio/experimentos/<ID>/`.
3. Define hipótesis, alcance y criterio PASS antes de programar.
4. Usa únicamente fixtures sintéticos.
5. Ejecuta `node laboratorio/check.mjs`.
6. Si pasa, revisa el diff y prepara la promoción mínima a CANON.
